Method

Every model answers the same items, so models are compared item by item. Intervals are 95% percentile bootstrap intervals with 10,000 resamples; differences resample items, keeping the pairing. 0/1 metrics are tested with the exact McNemar test, other metrics with a paired sign-flip permutation test (exact when the scores lie on a grid such as 0, 0.5, 1; otherwise 10,000 random sign flips). Holm's correction controls the family-wise error rate at alpha = 0.05: across model pairs for each metric in the comparison table, and across slices of one candidate for each metric in the slice tables. The minimum detectable effect uses Connor's (1987) normal approximation with the observed disagreement rate. Seed 0: rerunning the report gives the same numbers.
